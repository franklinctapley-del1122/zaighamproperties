# Zaigham Properties

A React + Vite property website focused on DHA Lahore, Pakistan.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Scope

The website focuses on DHA Lahore. Dubai and UAE property pages are intentionally excluded.

## Important before launch

- Replace the demo WhatsApp number in `src/App.jsx` with the official business number.
- Verify all sample property listings and asking prices before publishing them as live inventory.
- File rates are indicative user-supplied reference figures dated 26 October 2026, not guaranteed live quotes.
