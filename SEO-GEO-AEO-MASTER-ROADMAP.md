# Zaigham Properties — SEO, GEO & AEO Master Roadmap

**Project:** Zaigham Properties  
**Primary market:** DHA Lahore, Pakistan  
**Primary conversion:** Qualified WhatsApp enquiries and advisory consultations  
**Approach:** Audit existing URLs first, then improve one page at a time. Do not create thin pages merely to increase URL count.

## Strategic positioning

Position the business as a DHA Lahore property advisory and market-intelligence resource, not only a property-listing directory. Emphasise genuine local knowledge, property assessment, file-market understanding, buyer/seller matching, strategic plot pairing and portfolio review. Do not promise returns, guaranteed premiums, guaranteed appreciation or unverified availability.

Dubai/UAE is outside the business scope and must not be targeted.

## Working rules

1. One primary search intent per page; avoid competing pages targeting the same query.
2. Every indexable page must provide distinct, useful, accurate information.
3. Separate asking price, investor offer, client demand, estimated range and confirmed deal.
4. Every rate needs a date, rate category, source/confidence and owner approval before publication.
5. Keep client names, plot numbers and private negotiation details unpublished unless explicitly approved.
6. Verify phase, block, sector, facilities, maps and property status before making specific claims.
7. Use internal links between parent hubs, phase pages, block pages, service pages and guides.
8. Add structured data only when it accurately describes visible page content.
9. Keep redirects and canonical URLs consistent; sitemap should contain canonical indexable URLs only.
10. GEO/AEO improvements support clarity and discoverability; they do not guarantee AI citations or rankings.

## Phase 0 — Inventory, crawl and baseline

**Goal:** Establish the real state of the site before editing content.

- Crawl every route from the app and XML sitemaps.
- Compare routes against page-sitemap, phase-sitemap, block-sitemap and listing-sitemap.
- Identify missing pages, duplicate pages, redirect chains, 404s, soft 404s and orphan pages.
- Check title, meta description, canonical, H1, robots directives, status code and internal links.
- Check mobile layout, image alt text, image sizes, Core Web Vitals and accessibility basics.
- Check whether React route content is rendered and discoverable by search engines.
- Record Google Search Console indexing, impressions, clicks, queries and page performance where access is available.
- Establish baseline for WhatsApp clicks and enquiry conversions.

**Deliverable:** URL inventory and page-by-page issue register. No mass publishing during this phase.

## Definition of done for each page

A page is complete only when:
- Search intent and primary keyword are defined.
- Title, meta description, canonical and H1 are correct.
- Content is original, useful and fact-checked.
- GEO entity/context details are consistent.
- AEO direct answer and relevant FAQs are present.
- Internal links and CTA work.
- Images have accurate alt text and acceptable performance.
- Schema matches visible content.
- URL is in the correct sitemap if indexable.
- Page is checked on mobile and desktop.
- Changes are committed and production deployment is verified.

## Owner inputs needed when relevant

The owner supplies market facts, verified rates, phase/block knowledge, business details and approval to publish sensitive or commercially specific information. The assistant structures the information, writes/updates page content, maintains the ledger, implements code changes and checks deployment. No rates, transactions, credentials, inventory or returns will be invented.
